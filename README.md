# Autocorrect: תרגום ותיקון בלחיצה

מסמנים טקסט בכל תוכנה או אפליקציה (פייסבוק, וורד, ג'ימייל, וואטסאפ ועוד), לוחצים, והטקסט מוחלף אוטומטית בגרסה מתורגמת או מתוקנת. התרגום טבעי, לא מילה במילה, ושומר על שורות, אימוג'ים, האשטגים וקישורים.

---

## ללקוחות: התקנה

| מכשיר | מה מורידים | איך משתמשים |
|---|---|---|
| **Windows** | `AutocorrectSetup.exe` | מסמנים טקסט ולוחצים על `Ctrl+Alt+E` (לאנגלית), `Ctrl+Alt+H` (לעברית) או `Ctrl+Alt+F` (תיקון) |
| **Mac** | `Autocorrect.dmg` | אותם קיצורים: `Ctrl+Option+E` / `H` / `F` |
| **Android** | `Autocorrect.apk` | מסמנים טקסט ובוחרים „תרגום ותיקון“ בתפריט שנפתח |
| **Ubuntu** | `install-ubuntu.sh` | ראו את הסעיף Ubuntu בהמשך |

אחרי ההתקנה נפתח מסך הגדרות. מזינים בו את **קוד הגישה** שקיבלתם ולוחצים „שמירה ובדיקה“. זה הכול. במחשב, האפליקציה יושבת כאייקון ליד השעון, ושם נמצאים ההגדרות והיציאה.

**הפעם הראשונה ב-Mac:**
1. גוררים את Autocorrect לתיקיית Applications.
2. בפתיחה הראשונה לוחצים קליק ימני על האפליקציה ובוחרים **Open**. זה נדרש כל עוד האפליקציה לא חתומה באישור של Apple.
3. מאשרים ל-Autocorrect הרשאות ב-System Settings, ב-Privacy & Security, תחת **Accessibility** וגם **Input Monitoring**.

**Android:** בפעם הראשונה הטלפון יבקש לאשר התקנה „ממקור לא ידוע“. אחרי שהאפליקציה תעלה ל-Google Play, זה לא יהיה נדרש.

## לבעל השירות

### מבנה הפרויקט

| חלק | קבצים |
|---|---|
| שרת: מחזיק את מפתח ה-AI ומנהל קודי גישה | `server/` (ראו [server/README.md](server/README.md)) |
| אפליקציית מחשב: אייקון ליד השעון, קיצורי מקלדת, דף הגדרות | `desktop_app.py`, `autocorrect.py`, `settings_web.py`, `settings.html` |
| קובצי התקנה למחשב | `packaging/` |
| אפליקציית Android | `android/` |
| לוגיקה משותפת: ההנחיות ל-AI והספקים | `autocorrect_core/` |

### איך מקבלים את קובצי ההתקנה

כל הקבצים נבנים אוטומטית ב-GitHub, בלי להתקין כלום:

- **גרסת בדיקה:** בלשונית **Actions** בוחרים את ההרצה האחרונה של "Desktop installers" או "Android APK", ומורידים את הקבצים תחת **Artifacts**.
- **גרסה ללקוחות:** יוצרים תגית גרסה, למשל `v1.0.0`. כל הקבצים מתפרסמים יחד בדף **Releases**, וזה הקישור שנותנים ללקוחות.

**כתובת השרת בתוך האפליקציות:** ב-GitHub, ב-Settings, תחת Secrets and variables, ב-Actions, בלשונית Variables, מוסיפים משתנה בשם `AUTOCORRECT_SERVER_URL`. כך כתובת השרת נבנית לתוך כל האפליקציות, והלקוחות מזינים רק את הקוד.

### מעבר בין שיטות

כל החלקים עובדים עם אותם ספקי AI, ומחליפים ביניהם בהגדרה, בלי לשנות קוד:

| שיטה | שרת | מחשב (דף ההגדרות) | Android (מסך ההגדרות) |
|---|---|---|---|
| השרת שלכם עם קוד גישה | | „קוד גישה“ | „קוד גישה“ |
| Claude ישירות | `anthropic` | „מפתח AI משלי“, ואז Claude | דרך OpenRouter |
| OpenRouter | `openrouter` | „מפתח AI משלי“, ואז OpenRouter | „מפתח משלי“, ואז OpenRouter |
| OpenAI או שירות תואם אחר | `openai_compatible` | „מפתח AI משלי“, ואז OpenAI או „אחר“ | „מפתח משלי“, ואז OpenAI או „אחר“ |

- **בשרת** אפשר לרשום כמה ספקים בסדר עדיפות. אם הראשון נופל, עוברים אוטומטית לבא בתור. ההחלפה היא פקודה אחת, בלי הפעלה מחדש.
- **במחשב** ההגדרות נשמרות ב-`config.json` בתיקיית המשתמש:
  - Windows: `%APPDATA%\Autocorrect`
  - Mac: `~/Library/Application Support/Autocorrect`

  גם שם אפשר לרשום כמה ספקים, תחת `providers`.

### Ubuntu

```bash
chmod +x install-ubuntu.sh
./install-ubuntu.sh
```

הסקריפט רושם את הקיצורים כקיצורי מקלדת של המערכת. אחרי ההתקנה ממלאים את `providers` ב-`config.json`.

- **ב-Xorg** הטקסט מוחלף אוטומטית.
- **ב-Wayland** (ברירת המחדל מ-Ubuntu 22.04) קופצת התראה כשהטקסט מוכן, ולוחצים `Ctrl+V`. הסיבה היא ש-Wayland לא מאפשר לתוכנות ללחוץ על מקשים בעצמן.

### הרצה מהקוד (לפיתוח)

```bash
pip install -r packaging/requirements-desktop.txt
python desktop_app.py      # אייקון ליד השעון ודף הגדרות
python autocorrect.py      # גרסת טרמינל
```
