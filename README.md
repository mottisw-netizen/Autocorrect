# Autocorrect: תרגום ותיקון בלחיצת מקש

מסמנים טקסט בכל תוכנה (פייסבוק, וורד, ג'ימייל, וואטסאפ ווב ועוד), לוחצים על קיצור מקשים, והטקסט המסומן מוחלף אוטומטית בגרסה המתורגמת או המתוקנת.

| קיצור | מה הוא עושה |
|---|---|
| `Ctrl + Alt + E` | מתרגם לאנגלית (ומתקן שגיאות) |
| `Ctrl + Alt + H` | מתרגם לעברית (ומתקן שגיאות) |
| `Ctrl + Alt + F` | מתקן שגיאות כתיב ודקדוק, בלי לשנות שפה |

התרגום והתיקון נעשים על ידי Claude (של Anthropic). התרגום טבעי, לא מילה במילה, ושומר על שורות, אימוג'ים, האשטגים וקישורים.

## מבנה הפרויקט

| חלק | תיקייה | למי |
|---|---|---|
| שרת שמחזיק את מפתח ה-AI ומנהל קודי גישה | `server/` | בעל השירות. ראו [server/README.md](server/README.md) |
| אפליקציית Android (כפתור בתפריט סימון הטקסט) | `android/` | לקוחות |
| אפליקציית מחשב (קיצורי מקלדת) | `autocorrect.py` | לקוחות |

**אפליקציית Android:** מסמנים טקסט בכל אפליקציה ובוחרים „תרגום ותיקון“ בתפריט שנפתח. קובץ ההתקנה (APK) נבנה אוטומטית ב-GitHub, בלשונית Actions, בהרצה של "Android APK", תחת Artifacts. כדי שהלקוחות יזינו רק קוד ולא כתובת שרת, מגדירים ב-GitHub משתנה בשם `AUTOCORRECT_SERVER_URL` (ב-Settings, תחת Secrets and variables, ב-Actions, בלשונית Variables).

**אפליקציית המחשב** עובדת בשתי דרכים. בדרך הראשונה, ללקוחות, ממלאים ב-`config.json` את `server_url` ואת `access_code`. בדרך השנייה, לשימוש עצמי, ממלאים מפתח Claude משלכם ב-`api_key`.

## התקנה (פעם אחת)

1. **התקינו Python** מהאתר https://www.python.org/downloads (ב-Windows סמנו את האפשרות "Add Python to PATH").
2. **הריצו את התוכנה פעם אחת.** ייווצר קובץ `config.json` בתיקייה.
3. **פתחו את `config.json`** ומלאו בו כתובת שרת וקוד גישה (`server_url` ו-`access_code`), או מפתח Claude משלכם (`api_key`, מ-https://platform.claude.com).

## הפעלה

- **Windows:** לחיצה כפולה על `start-windows.bat`
- **Mac:** לחיצה כפולה על `start-mac.command`. בפעם הראשונה צריך לאשר הרשאות ב-System Settings, ב-Privacy & Security, תחת **Accessibility** וגם **Input Monitoring**, עבור ה-Terminal.

ההפעלה הראשונה מתקינה את מה שצריך ולוקחת כדקה. אחר כך החלון נשאר פתוח ברקע, ואפשר להשתמש בקיצורים בכל מקום.

### Ubuntu

```bash
chmod +x install-ubuntu.sh
./install-ubuntu.sh
```

הסקריפט מתקין את הכלים הדרושים ורושם את הקיצורים כקיצורי מקלדת של Ubuntu (אפשר לראות ולשנות אותם ב-Settings, תחת Keyboard, ב-Custom Shortcuts). אין צורך להשאיר חלון פתוח: הקיצורים פשוט עובדים. אחרי ההתקנה מכניסים את המפתח ב-`config.json`.

- **Xorg / X11:** הכול אוטומטי. מסמנים, לוחצים, והטקסט מוחלף.
- **Wayland** (ברירת המחדל מ-Ubuntu 22.04): מסיבות אבטחה, Wayland לא מאפשר לתוכנות "ללחוץ" על מקשים. לכן כשהטקסט מוכן קופצת התראה, ולוחצים `Ctrl+V` כדי להחליף את הטקסט המסומן. כדי לקבל הדבקה אוטומטית, בוחרים "Ubuntu on Xorg" במסך הכניסה (גלגל השיניים בפינה).
- אם משנים קיצורים ב-`config.json`, מריצים שוב את `install-ubuntu.sh`.

## התאמה אישית (`config.json`)

- **שפות נוספות:** אפשר להוסיף קיצור, למשל צרפתית:
  ```json
  "<ctrl>+<alt>+r": {"action": "translate", "target": "French"}
  ```
- **`effort`:** הערך `low` הוא המהיר ביותר. הערך `medium` או `high` איטי יותר אבל מקפיד יותר.
- **`model`:** המודל של Claude שבו משתמשים.

## איך זה עובד

התוכנה מעתיקה את הטקסט המסומן, שולחת אותו ל-Claude ומדביקה את התוצאה במקום הטקסט המקורי. מה שהיה ב-Clipboard לפני כן מוחזר אחרי ההדבקה.
